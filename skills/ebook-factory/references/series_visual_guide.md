# 开窍系列（××开窍）视觉与封面统一规范

> 三本已出版：《社会化开窍指南》《搞钱开窍》《识人辨局》。这是"开窍系列"的视觉与文案统一模板，新建系列书时直接套用，仅改文案、按主题微调配色强调色。

## 一、封面结构（CSS 已在 build_book.py 内，勿改布局）

- 外层 `.cover`：米色底 `#f4efe6`，flex 居中
- 内层 `.cover-inner`：深色渐变卡片 `linear-gradient(160deg,#1c1f26 0%,#2b2d3a 55%,#3a2f22 100%)`，文字 `#f0e9d8`，圆角 8px + 阴影
- 点缀金 `#c9a227`：kicker 字色、分隔线、正文小节标题、目录下划线、话术模板框 —— 全书统一
- 封面元素自上而下：`kicker`（顶部小字）→ `title`（大标题）→ `line`（金线）→ `sub`（封面副线）→ `desc`（描述）→ `author`

## 二、封面文案公式（每本照此填）

### kicker（顶部小字）
`普通人的[领域]底层/处世心法`
- 社交处世书：`普通人的处世底层心法`
- 搞钱书：`普通人的搞钱底层心法`
- 识人局书：`普通人的识人与控局心法`

### title（主标题）
`[三字/短词]开窍`，例如 社会化开窍指南 / 搞钱开窍 / 识人辨局（首本带"指南"，续本二字，可自由定）

### toc_track（封面副线）
由全书各章提炼成 5-6 段递进，段间用 ` · ` 连接，格式固定为"从A到B · 从C到D"。
- 范例（社会化）：`从心态到表达 · 从破冰到识人 · 从职场到处世 · 从边界到人脉 · 从认知到布局`
- 范例（搞钱）：`从认知到杠杆 · 从副业到流量 · 从产品到营销 · 从复利到信息差 · 从风险到布局`
- 范例（识人辨局）：`从人性到动机 · 从识人到辨局 · 从博弈到话术 · 从防身到布局 · 从控局到格局`

### desc_lines（封面描述，2 行）
- 第 1 行：`一套帮你[从根上解决的核心命题]的开窍宝典`
- 第 2 行：`不[反约束A] · 不[反约束B] · [目标读者痛点解决后的状态]`

## 四、序言与结语的"开窍"体结构（三本一致的骨架）

**序言（4 段式）**
1. 点破一个"你越X越吃亏/越努力越没结果"的核心认知盲区（先抛结论）
2. 指出现有方法/路径为什么错（不是你不努力，是方法底层就错了）
3. 本书给三样东西（通常是"一双眼睛/一张地图/一身护甲"式的排比，紧扣主题）
4. 承诺：不灌鸡汤/不教XX，每节落到"能用"，读者读完当天就能用一两条

**结语（3 段式）**
1. 收束：主题的本质是"XX，不是XX"的认知
2. 泼冷水 + 三句可背的行动赠言（"第一/第二/第三"或"看人…/看局…"短句）
3. 一句终局赠言收尾，落点在"开窍之后才是开始 / 你这一盘该自己下"这类有分量的话

## 五、全书通用约束

- 章标题：`第X章 [主题]篇｜[副题承诺]`；主题用单字/双字（心态、破冰…/认知、杠杆…/人性、动机…），首字大写风格统一
- 小节标题：`X.Y 一句话结论式标题`
- 每小节：结论句开头 → 痛点场景 → 底层逻辑 → 「」话术模板 → 场景演练 → 一句收束
- 内容红线：不教违法/阴损/坑人，价值观正向，讲体面自保与正向竞争
- 封面视觉与版式：三本已统一，新书复制 build_book.py 到项目目录即可，仅改 CONFIG 文案
