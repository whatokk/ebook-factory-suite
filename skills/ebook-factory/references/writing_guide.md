# 知识付费电子书写作规范（通用版）

> 本规范适用于「口语化实战风」的知识付费电子书。复制到项目内作 `WRITING_GUIDE.md`，供写手 / Agent 必读。

## 一、全书定位（每本先定）

- 目标读者是谁、他们最痛的 1-3 个问题是什么
- 一句话内核（这本书到底帮读者换什么脑子）
- 不教什么（红线）

## 二、语言风格（硬性要求）

1. 口语化、朋友聊天式，像老友掏心窝子，绝不端架子、不说教
2. **先抛结论，再展开**；每小节结尾一句点题收束
3. 通篇用"你"直呼读者，场景化代入，多写真实画面
4. 禁用：首先/其次/最后、综上所述、总而言之、不难发现、众所周知、相信通过…… 等官腔与 AI 味词
5. 短句为主，节奏利落；可适度用"说白了""你想想""对吧"（全文不超过 3 处）
6. 不用 emoji，不用网络烂梗，不用感叹号堆砌
7. 话术模板用引号单独标出成段，方便读者抄走就用

## 三、每小节结构模板（按序）

1. **结论句开头**（1 句，点破核心）
2. **痛点场景**（1-2 段，读者真实遇到的尴尬/憋屈画面）
3. **底层逻辑拆解**（1-2 段，大白话讲透原理）
4. **方法/公式/步骤**（给可执行之物，务必带「话术模板」或清单，具体到能背）
5. **场景演练**（1 个实例对话/演示）
6. **一句收束**（点题，简短有力）

## 四、每章结构

- 章引言：150-250 字，先抛本章最大结论，点明解决什么问题
- 6-7 个小节，每节 850-950 字
- 章末不写总结（避免废话）

## 五、内容红线

- 不教违法、不教阴损坑人手段；涉及"反击/权谋/博弈"时讲体面自保、正向竞争、格局提升
- 价值观正向：鼓励靠实力、真诚、利他，不鼓励玩弄人心
- 不贬低性格特质（如内向/社恐不是病，是待解锁的开关）
- 每节必须让读者"读完就能用"，禁止空谈
