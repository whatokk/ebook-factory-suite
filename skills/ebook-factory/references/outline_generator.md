# 开窍系列 · 章节骨架生成模板

> 用统一方法论把任意"主题"拆成一本开窍书的章节骨架。所有新书都按此设计 OUTLINE，保证系列结构、深度、红线一致。

## 一、"开窍"系列的底层结构规律（三本验证）

开窍书=帮读者把一个**领域的底层逻辑想通**。核心不是列技巧，而是：**先破除旧认知 → 建立新框架 → 给可执行动作**。

三本共有的黄金结构，按读者心智顺序推进（内→外→再站高一层）：

```
第1章  底层认知（破除误解，重建这个领域的"第一性原理"）
第2章  核心机制（领域真正的运转逻辑）
第3章  关键技法1（读者最容易卡住的实操入口）
第4章  关键技法2（放大收益/进阶）
第5章  进阶/避坑（走快与防错）
第6章  人情/资源/关系面（对象是人，绕不开人际）
第7-9章  纵深主题（按领域深入，每章聚焦一个大模块）
第10章 终局/格局（收束到"你要成为什么样的人/过什么样的生活"）
```

> 每章 6-7 节，全章 6-10 章（标准版 10 章，精炼 6-7 章，深度可到 12 章）。每章一个单字/双字"篇"名（心态、破冰、认知、杠杆、人性、动机、布局…），对应一层认知。

## 二、设计任意主题的章节骨架（四步）

### Step 1 定"内核一句话"
回答：这本书帮读者**换掉哪个错误认知**？（例如搞钱书：不是靠出卖时间换钱，是靠杠杆×价值。）这句话决定全书主线。

### Step 2 定"读者是谁 + 最痛的三点"
标出目标读者和他们的 3 个具体痛点，每章至少精准命中一个。

### Step 3 定"章名清单"（先不定节）
按上面的黄金结构，写出 6-10 个"篇"名 + 每篇一句话副题承诺。例如社交书：心态/破冰/表达/识人/职场/处世/边界/反击/人脉/认知。

### Step 4 每章定节（每节一句话核心结论）
每章 6-7 节，每节一句**"认知翻转"式结论**（如"钱是按解决问题大小结算，不是按流汗多少"）。这句结论是 Agent 写作时唯一锚点，务必写清、写具体——**这是多 Agent 产出不跑偏的关键**。

## 三、红线（所有主题通用，写进每本 OUTLINE 末尾）
- 不教违法/阴损/坑人害人；凡涉"权谋/博弈/反击/控局"讲体面自保、正向竞争、长期共赢
- 涉及"骗局/割韭菜/风险"主题：重心放在教识别与自保，绝不教操控/诈骗/操纵
- 价值观正向：鼓励靠实力、真诚、利他；不鼓励玩弄人心、不鼓吹一夜暴富
- 不贬低性格特质（内向/社恐是待解锁的开关，不是缺陷）
- 每节必须落到"读完能用"，禁止空谈

## 四、存量主题 → 已有骨架速查（若复用，直接取）
- 社交处世 → 《社会化开窍指南》OUTLINE（心态/破冰/表达/识人/职场/处世/边界/反击/人脉/认知）
- 搞钱变现 → 《搞钱开窍》OUTLINE（认知/杠杆/副业/流量/产品/营销/复利/信息差/风险/布局）
- 识人辨局 → 《识人辨局》OUTLINE（人性/动机/识人/局/博弈/话术/防身/布局/控局/格局）

## 五、常见可用主题的章名提案（可直接落地）
- **逆袭破圈**：认知→选择→能力→作品→破圈→借势→复利→防守→爆发→自由
- **超级爆款/内容**：定位→选题→结构→文案→流量→私域→转化→迭代→矩阵→心法
- **职场晋升**：定位→向上→价值→汇报→关系→边界→谈判→跳槽→格局→自由
- **婚姻家庭**：认知→沟通→分工→经济→婆媳→育儿→冲突→修复→边界→幸福
- **副业变现（单主题展开）**：定位→技能→选型→MVP→流量→转化→交付→放大→复利→闭环
