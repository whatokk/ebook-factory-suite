# 复刻批量化：章节轨道、道具载体、禁用词与套话分层

本文件是 `ebook-replica-batch` skill 的参考数据。复刻电子书20 实战验证过（20 本 / 68.2 万字 / 1,158 个「」话术模板 / 881 页），可直接套用。

## 一、章节轨道 `toc_track`（因店而异）

每本书 `config.json` 的 `toc_track` 用 `·` 分隔 7 个轨道名，决定应有哪 9 个章节文件：
`00_preface.md` + `01_<轨道1>.md` … `07_<轨道7>.md` + `08_afterword.md`。
`qc.py` 据此动态推导章节清单，**不硬编码骨架**。

### 四店 / 四类轨道（实测对应）

| 店铺 / 批次 | toc_track（7 轨） | 对应书号 |
|---|---|---|
| 台球界徐志摩 | 认知·模式·系统·产品·流量·人性·破局 | 01–09 |
| 人性智慧研修 | 认知·人性·阶层·识人·自保·关系·改局 | （同结构可微调；实际用 改命） |
| 银河知识 | 认知·心法·表达·谋略·兵法·修身·破局 | 11–15 |
| 开悟阅读01 | 认知·生意·需求·执行·变现·经营·格局 | 16–20 |
| 打开慧眼（独立轨道） | 认知·人性·阶层·识人·自保·关系·改命 | 10 |
| 给30岁普通人一个忠告 | 认知·模式·系统·产品·流量·人性·破局 | 08 |

> 注：轨道名即章节 H1 章名；写手产出后 `qc.py` 会比对 `toc_track` 与正文 H1 是否一致。新店照此四选一或自定 7 轨（认知必为第 1 轨，破局/改命/格局类收尾为第 7 轨）。

## 二、硬套话 vs 软修辞分层（去重核心方法论）

**原则**：硬套话（固定公式）必须归零；软修辞（自然行文）只控密度、不强求归零。把两者混为一谈会误删自然汉语、破坏文风。

### 硬套话（正则族，必须归零）

抓取用正则族而非字面串（正文是变体，字面串漏报）：

```
读完这一[章篇] / 读到这一[章篇] / 读到末尾
这一[章篇]讲的是 / 这一[章篇]讲的就是 / 这一[章篇]要解决
前面[一二三四五六七八九十]+[章篇]讲的是
手机备忘录 / 备忘录 / 小到不可能失败
他给自己定了个规矩 / 后来他给自己定 / 自己定了个规矩
给自己定了一条铁 / 给自己定一条铁
[一个]?反常识的结论
判断标准(很简单|只有一|其实很简单|特别清楚)
最容易被忽略的 / 第一个想到的就是
这本书从头到尾 / 真正拉开差距的 / 决定你能走多远
给你一个(能直接|立刻能|判断标|能跑)
还有个隐形好处 / 还有一点要提醒 / 还有一件事你要
问自己三个问题 / 和做到之间隔着 / 不可怕可怕的是
```

典型固定句式（逐本清零）：
- 章节预告：`前面几章讲的是…` / `这一章讲的是…`
- 道具复用：`手机备忘录`（被 10+ 本共用必须拆分）
- 话术引导：`给你三句能直接抄走的话` → 每本换说法（`下面三句，照着说就行`/`这三句挡话，你留着用`…）
- 收束套话：`把这本书翻回来，一章一章照着做`（4 本同款 → 每本换收束）

### 软修辞（自然行文，只监控密度，不要求归零）

```
你有没有(过|这种|见过|发现|遇到|碰过|遇过)
你一定(有过|见过|也|遇到|碰过)
你肯定(有过|见过)
很多人
```

> 全库「很多人」数百处属汉语最普通行文词；「你一定见过这种…」作为痛点开场框架，单本 ≤3 处可接受，超过需打散（参考 08 号书把 6 处 opener 拆成「这种憋屈就在这儿/类似的戏码天天上演/这种人在身边到处都是…」）。

### 通用搭配 / 自然汉语白名单（误报分流，不要求清零）

- 通用搭配：`的是完全不同的` / `最容易犯的错是` / `的时候你会发现` / `的一件事是什么`
- 自然汉语（带证据入 `NATURAL`）：`他跟我说我不是`（引语框）/ `不是能力问题是`（对照）/ `他说我卖的不是` / `这笔账怎么算都` / `人值不值得深交` / `和做到之间隔着` / `怀疑自己是不是` / `不是想出来的是` / `不是天生的性格` / `很多人卡在这一` …
  判据：① 每本落在不同句子、句意各不同；② 去掉反而不自然；③ 同结构固定公式句已清零。

## 三、道具载体逐本差异化分配表（防跨书撞车）

**铁律**：杜绝一个载体被多本共用（如「手机备忘录」被 10+ 本共用）。每本分配唯一载体：

| 书号 | 载体 | 书号 | 载体 |
|---|---|---|---|
| 01 | 微信收藏 | 11 | 一张草稿纸 |
| 02 | 一张便利贴 | 12 | 两人共用的在线文档 |
| 03 | 随身的小账本 | 13 | 名片背面（原语音录音） |
| 04 | 电脑桌面文档 | 14 | 贴在桌角的纸条 |
| 05 | 台历背面空白处 | 15 | 常翻书的页边空白 |
| 06 | 微信文件传输助手 | 16 | 一张 Excel 表 |
| 07 | 一本专用笔记本 | 17 | 微信发给自己的一条消息 |
| 08 | 一块白板 | 18 | 一张 A4 纸贴墙上 |
| 09 | 手机相册截图 | 19 | 账号后台草稿箱 |
| 10 | 一张手写卡片 | 20 | 手机日历备注栏 |

> 写手写「方法」段时，从分配表取本书专属载体，不要随手写「手机备忘录」。

## 四、12 个硬禁用词（全库命中必须 = 0）

```
首先　其次　最后　综上所述　总而言之　不难发现
众所周知　相信通过　一方面　另一方面　值得注意的是　在这个时代
```

> 注：「最后一个」也算禁用；自己新写的内容也会带进禁用词，写完必须复扫（Grep 全量）。

## 五、写作六段式（每小节固定 6 段，红线）

1. **结论句开头**（1 句点破本节核心）
2. **痛点场景**（1~2 段真实尴尬/憋屈画面）
3. **底层逻辑拆解**（大白话讲透原理）
4. **方法/公式/步骤**（含「」话术模板，单独成段、可直抄）
5. **场景演练**（1 个实例对话/演示）
6. **一句收束**（点题，简短有力）

红线（通用）：正向、合法、不教阴损/违法；涉权谋/博弈讲体面自保与正向竞争；涉风险教识别与自保；口语化、先结论、称「你」、禁官腔词、不用 emoji、每节落到「能用」。完整写作规范见 `ebook-factory/references/writing_guide.md`。
